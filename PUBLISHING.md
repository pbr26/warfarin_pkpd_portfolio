# Publishing to Posit Connect Cloud

The report is designed to publish cleanly on **Posit Connect Cloud**
(<https://connect.posit.cloud>). Connect Cloud renders your Quarto document
from a **GitHub repository**, so the flow is: run the pipeline locally → push
to GitHub → publish.

Because `analysis.qmd` only *embeds* pre-computed figures and tables (no model
fitting, no code chunks at render time), the cloud render is fast and does not
need to install `nlmixr2`.

---

## Step 1 — Generate the report assets locally

In RStudio, with the project open, run the pipeline once so the figures and
tables exist:

```r
source("setup.R")
source("scripts/01_data_cleaning.R")
source("scripts/02_EDA.R")
source("scripts/03_PK_Model.R")
source("scripts/04_PD_Model.R")
source("scripts/05_PKPD_Model.R")
source("scripts/06_Model_Diagnostics.R")
source("scripts/07_Simulation.R")
source("scripts/08_report_tables.R")   # exports the markdown tables
```

Check that these exist and are non-empty:

- `figures/02_*.png`, `figures/06_*.png`, `figures/07_*.png`
- `reports/results/*.md`

> If the VPC step in script 06 was skipped, `figures/06_vpc.png` won't exist —
> either re-run 06 until it produces the VPC, or delete the VPC image line in
> `analysis.qmd` so the report doesn't reference a missing file.

Optional: render locally first to confirm it looks right:

```r
quarto::quarto_render("analysis.qmd")
# open reports/ or the generated analysis.html
```

## Step 2 — Put the project on GitHub

If it isn't a repo yet:

```bash
cd "warfarin_pkpd_portfolio"
git init
git add .
git commit -m "Warfarin PK/PD portfolio: analysis + report"
```

Create an **empty** repository on GitHub (no README), then:

```bash
git remote add origin https://github.com/<your-username>/warfarin_pkpd_portfolio.git
git branch -M main
git push -u origin main
```

The `.gitignore` is set up to commit the figures and `reports/results/*.md`
(needed to render) while ignoring large model objects and working data.

## Step 3 — Publish on Posit Connect Cloud

1. Go to <https://connect.posit.cloud> and sign in with your GitHub account.
2. Click **Publish** → choose **Quarto**.
3. Authorize Connect Cloud to access your GitHub, then pick:
   - the **repository** (`warfarin_pkpd_portfolio`)
   - the **branch** (`main`)
   - the **primary document**: `analysis.qmd`
4. Click **Publish**. Connect Cloud clones the repo, renders the report, and
   gives you a public URL to share.

## Step 4 — Updating the published report

Re-run the affected scripts locally (e.g. `02` and `08` if you changed a
figure), commit, and push:

```bash
git add figures reports/results analysis.qmd
git commit -m "Update figures and results"
git push
```

Then click **Republish** (or enable auto-publish on push) in Connect Cloud.

---

## Troubleshooting

- **Broken image in the report** → a referenced PNG wasn't committed. Confirm
  it exists under `figures/` and isn't blocked by `.gitignore`, then push.
- **Connect Cloud asks for R package dependencies** → the report has no R code
  chunks, so it should render as plain Quarto. If prompted, you only need
  `quarto`/`rmarkdown`; you do **not** need `nlmixr2` for the report.
- **Tables not showing** → make sure `reports/results/*.md` were generated by
  `scripts/08_report_tables.R` and committed.
